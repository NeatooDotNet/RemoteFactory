- **The denial paths match the plan's Current State, with one exception.** The interface builder alone passes `aspForbid: true` (`FactoryModelBuilder.cs:437`). The exception is the anonymous user, callout 1.

The library's own `AspAuthorize` has never been run over HTTP: no test project hosts `RemoteFactory.AspNetCore.TestServer`.
